ЕДИНАЯ АДМИНКА DIRECTUS — 02.10.2026

Этот пакет материалов находится в D:/codex/Universal Commerce CMS/docs/admin-sections.

1. Откройте mockups.html в браузере. Макет автономный: 14 разделов, вкладки,
   списки/карточки, мобильный режим и состояния ошибок; данные не отправляются в CMS.
2. TASK-INDEX.md связывает секционные ТЗ и LAUNCH-задания.
3. PLAN.md описывает этапы, зависимости и границы параллельной работы.
4. DESIGN-SYSTEM.md и CONTRACTS.md задают общие UI/API-ограничения.
5. A0-задание находится в foundation/LAUNCH.md; затем используйте нужный
   sections/<collection>/LAUNCH.md вместе с этим пакетом.

Каждая секция включает ТЗ, карты полей, JSON schema, синтетический offline fixture,
маршруты и ссылку на макет. Fixture запрещено импортировать в CMS. Товары —
ранее реализованный эталон для регрессии; из 14 секций только он уже имеет
реализацию. Документы и макеты не обещают реализации остальных редакторов.

G1/G2 — отдельные зависимости API/identity, которые нельзя включать молча.
Системные экраны Directus описаны в NATIVE-SURFACES.md.

Перед каждой будущей работой проверьте чистую task branch/worktree от актуального
HEAD destination. Старый SHA и состояние исходного проекта относятся только к
архивной истории в SOURCE-PROVENANCE.md. Снимок схемы статический, не live export.
