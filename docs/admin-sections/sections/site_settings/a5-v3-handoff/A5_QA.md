# A5 v3 — фактическая проверка

## Проверяемая поверхность

Автономный `A5_settings_v3.html`, исполненный Chromium в Linux. HTML и скрипты загружены в браузер через `page.set_content`, затем выполнены реальные клики, ввод, выбор файла, проверка фокуса и снимки экрана. Статическая картинка вместо интерфейса не использовалась.

В доступном подключённом Browser были только функции чтения вкладок, без управления и снятия экранов. Поэтому использован Playwright с установленным `/usr/bin/chromium`. Доступ к `file://` в этой среде ограничен политикой; документ загружался непосредственно в браузер. В реальный Windows Directus подключение/установка не выполнялись.

## Результат

- 7 проверок модели offline-редактора: PASS.
- 12 записанных браузерных сценариев/контрольных результатов: PASS.
- Размеры: 1536×1024, 1024×768, 390×844, 320×720.
- Ошибки JavaScript браузера: 0 в проверенных сценариях.
- Внешние HTTP-запросы от проверяемого HTML: 0.
- Горизонтальное переполнение документа: не обнаружено в проверенных размерах и основных состояниях.
- Минимальный измеренный контраст среди проверенных информативных текстов: 5,50:1. Расчёт по вычисленным цветам DOM; это не заявление о полной доступности по WCAG.

## Исправления после осмотра

1. Убрана мобильная кнопка меню на desktop: причиной был каскад CSS общей кнопки.
2. Старое значение больше не дублируется над раскрытой краткой формой — не смешиваются сохранённый и новый ввод.
3. После Save фокус возвращается в соответствующее поле или кнопку краткого редактирования.
4. Ошибки не представлены одним цветом: есть текст и связь с полем.
5. Техническое выражение о структурированных данных заменено более понятной подписью для менеджера.

Визуально сопоставлены предоставленный v2 и реальные v3-снимки. Проверены плотность строк, место формы, читаемость, отсутствие чужого брендинга, единый Save и мобильное расположение действий. Это самопроверка, а не независимое ревью другого специалиста.

## Первичная регрессия

`tests/RED_v2.json` фиксирует до изменения два нарушения: контраст 2,90:1 и открытие реквизитов в модальном drawer. В новом документе эти сценарии проходят. `tests/RED_model.txt` и `GREEN_model.txt` фиксируют разработку проверяемой модели.

## Чего этот результат НЕ доказывает

Не выполнялись реальная запись в Directus/PostgreSQL, проверка реальных ролей, установка bundle, live CAS, проверка native file picker, реального кеша Next.js, private/public asset eligibility, Windows runtime, Safari/iPhone с системной клавиатурой, тёмная тема, скринридер, независимый review и пользовательское исследование.

`node scripts/verify-local.mjs` основного репозитория не запускался. Код репозитория не менялся и не объединялся. Этот отчёт не даёт разрешения на merge A5 в обход обязательной приёмки.

Перед завершением реального A5 обязательны перенос на A0, field-level контракт, native/runtime/visual проверки, независимое ревью и локальный gate на точном кандидате.
