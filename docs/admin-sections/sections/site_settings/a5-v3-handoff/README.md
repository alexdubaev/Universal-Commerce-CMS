# A5 v3 — «Настройки сайта»: материалы для интеграции

**Статус:** автономный интерфейс HTML и документация подготовлены. Реальный Vue-редактор `site_settings` в Directus **не реализован и не принят**. Эта папка — пакет передачи для следующего агента, не production-код.

## С чего начать

1. [AGENT_START.md](AGENT_START.md) — короткое вводное задание для Codex.
2. [A5_settings_v3.html](A5_settings_v3.html) — интерактивный HTML-эталон; открывать локально в браузере, без сервера.
3. [A5_IMPLEMENTATION_TZ.md](A5_IMPLEMENTATION_TZ.md) — основное подробное ТЗ для переноса в существующий Directus.
4. [A5_FIELD_CONSUMERS.md](A5_FIELD_CONSUMERS.md) — матрица 38 полей и их использования витриной.
5. [A5_DESIGN_DECISIONS.md](A5_DESIGN_DECISIONS.md) — UX-решения и сравнение с отраслевой практикой.
6. [A5_QA.md](A5_QA.md) — проверки **только автономного прототипа**, а не CMS.
7. [A5_HANDOFF.md](A5_HANDOFF.md) — состояние и ограничения передачи.
8. [A5_V3_INTERFACE_AND_TZ_2026-10-19.zip](A5_V3_INTERFACE_AND_TZ_2026-10-19.zip) — полный архив, включая `src/`, `tests/` и реальные снимки Chromium `screenshots/` для сравнения desktop/mobile.

## Приоритеты и ограничения

* Первичны свежие `AGENTS.md`, актуальный `origin/main`, `docs/architecture/ADR-002-scope-locked-changes-and-content-only-releases.md` и рабочий код. Исторические планы из родительской папки могут устареть.
* Дизайн v3: компактные строки обзора и быстрые правки для простых значений; объёмные формы внутри основной рабочей области, без универсальных боковых панелей; все рабочие подписи на русском.
* Это **один singleton** `site_settings`, не создавайте дополнительную запись или вторую админку. Изменения — только разрешённые поля и guarded CAS; служебные и секретные поля не редактировать.
* HTML-прототип и `src/model.mjs` из архива — исключительно визуально-поведенческий эталон. Нельзя импортировать демонстрационные данные, подключать макет через iframe или копировать его state/transport вместо A0.
* При первом переходе к реализации проверить существующие разрешения, реальные метаданные, форму ответа singleton, field-level контракт, права файлов и использование полей витриной. Реальная приёмка только на подтверждённом локальном Windows Directus.
* GitHub Actions не использовать. Перед merge — `node scripts/verify-local.mjs` и отдельная runtime/visual acceptance. Production deployment не входит в A5.

**Примечание по GitHub:** папка опубликована отдельным документационным кандидатом. Наличие файлов в ветке/PR не означает merge в `main` или установку в Directus. Воспроизводимые тесты и реальные скриншоты хранятся в ZIP.
