## Заказанная работа

**Только A4:** список и редактор существующей коллекции `articles` в собственном Directus. Публичная витрина читает HTML `articles.content`; `content_blocks` и `editor_nodes` НЕ конвертировать, НЕ очищать и НЕ заменять вторым редактором. Использовать нативные формы/права, CAS и MediaPicker. Дату `published_at` не путать с фактом публикации; права и статусы проверять на живом серверном контракте.

Создать собственную краткоживущую ветку/worktree от свежего `origin/main`, **не от ветки этого пакета**. Работать параллельно с A2/A3 только в независимых файлах; `src/index.js`/registry, общие примитивы и записи в один тестовый Directus согласовывать последовательно. Не переписывать CMS, API, схему, permissions или storefront.

Обязательная приёмка: адресные тесты и `node scripts/verify-local.mjs` на финальном кандидате; реальные скриншоты Directus desktop/mobile со сравнением с одобренным HTML, независимый review. Зелёные автотесты без визуальной приёмки — недостаточно для merge.

При полной зелёной приёмке агент самостоятельно выполняет push, PR, review и merge. После проверки `main` удаляет только свою собственную временную ветку/чистый worktree. Deploy — только в подтверждённую собственную инфраструктуру с backup/update/rollback. В конце один самодостаточный **копируемый Markdown HANDOFF**. После A4 остановиться.
