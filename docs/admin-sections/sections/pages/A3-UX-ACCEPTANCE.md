## Результат и границы

Содержимое страницы находится на вкладке «Содержимое», включая прежнее `seo_text` без преобразования хранения. Название для списка и заголовок посетителя остаются разными полями. Для новой обычной страницы русский заголовок предлагает латинский адрес; ручной адрес и адрес существующей записи не перезаписываются.

Поисковые настройки имеют один scalar-ввод и штатный выбор изображения. JSON-first fallback, обратное `no_index`, canonical в `additional_fields`, неизвестные свойства, CAS и серверный readback сохранены. Ни миграции, ни очистки старых данных нет. Карта реальных публичных потребителей — [A3-UX-CONSUMERS.md](A3-UX-CONSUMERS.md).

Новый authenticated read-only `GET /commerce/config/storefront` читает только `COMMERCE_STOREFRONT_URL` экземпляра. В общем коде нет домена/порта витрины по умолчанию. Ссылка использует проверенную базу и сохранённый допустимый адрес опубликованной записи; несохранённый slug её не меняет. Это обычная публичная ссылка, не предпросмотр черновика. Без базы или при ошибке чтения активной неверной ссылки нет.

Контекст списка хранит только запрос, фильтры, сортировку и страницу по принятому образцу категорий; metadata и permissions перечитываются. Серверные 25 строк и стабильный id tie-break сохранены; сортировки внутренних кодов статуса/типа удалены из UI. Пустая коллекция, пустая выдача, отсутствующая страница пагинации и ошибка различаются.

Сохранение страницы, публикация и сохранение каждого блока остаются отдельными действиями. Системные записи и `source_page` защищены; неподтверждённое чтение связи блокирует редактирование. Для фиксированных about/delivery/contacts/payment объяснено, что после снятия записи с публикации встроенная страница остаётся. Общая основа A0, схема, SQL, роли, credentials, storefront, зависимости и CI не менялись. В Compose добавлена только утверждённая передача URL.

## Ограничения

- Реального тестирования менеджером/новичком не было. Administrator UI и controlled permissions-response denial не доказывают права отдельной manager role; новые роли/аккаунты не создавались.
- Публичные фильтры/витрина читают существующие scalar-колонки. Прежняя несогласованная legacy запись JSON/scalar может отличаться от редакторского JSON-first представления до серверной синхронизации; A3 не мигрирует чужие старые записи и не меняет backend фильтра. Новая запись и scalar-save/readback проверены на реальном hook.
- Витрина сохраняет прежний кеш; опубликованные изменения могут появиться с задержкой. Открытие публичного URL не является предпросмотром черновика.
- Модальные native уведомления Directus о лицензии/project owner не требуют нового owner или прав для A3; при read-only capture они закрываются действиями «Пропустить» / «Remind Later» без настройки проекта.
