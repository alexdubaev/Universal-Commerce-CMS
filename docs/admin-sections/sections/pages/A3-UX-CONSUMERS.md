# A3-UX-FIX: фактические потребители полей

Сверено с исходниками на базе `22c2892e3ee632e0a08e0f9ba27bc47b7dc649bc`, 24.10.2026. Это карта существующего поведения; A3 не меняет витрину, схему или SEO hook. Исторические `FIELD-MAP.md`, `routes.md` и `A3-ACCEPTANCE.md` описывают прежние этапы, а не новую установленную версию.

| Данные | Существующий потребитель | Следствие для редактора |
|---|---|---|
| `title` | Список CMS, breadcrumb `CmsPageRenderer`, запасной metadata title и запасной h1 | «Название для списка» отличается от заголовка посетителя; переименование может также изменить breadcrumb и запасные значения витрины. |
| `h1` | Основной заголовок `CmsPageRenderer`; fallback `title` | Отдельное поле «Заголовок для посетителя», без автоматического копирования названия. |
| `slug` | `getCmsPage(slug)`, маршрут `app/[slug]/page.tsx` и фиксированные страницы | Новому черновику предлагается транслитерация. Ссылка использует сохранённый допустимый маршрут опубликованной записи. |
| `intro` | Текст под h1; запасное поисковое описание | Вкладка «Содержимое». |
| `seo_text` | `CmsPageRenderer`: видимый абзац после дочерних блоков | «Текст внизу страницы» находится в содержимом; значение и формат хранения не преобразуются. |
| `eyebrow` | Загружается `getCmsPage`, но текущий `CmsPageRenderer` его не рисует | Редкое дополнительное поле; не обещать появление на витрине. |
| `seo_title`, `seo_description` | Metadata и Open Graph; fallback к `title` / `intro` | Один основной scalar-ввод на вкладке «Поиск и ссылки». |
| `og_image` | Open Graph через собственный `/api/assets/:id` | Штатная библиотека файлов; отвязка не удаляет файл. |
| `canonical_url` | `safeCanonicalUrl` в metadata | Редкое раскрываемое поле. Не является базой кнопки открытия сайта. |
| `is_indexable` | Metadata robots; серверная SEO-проекция с обратным `no_index` | Понятный переключатель, сохранить null/false и серверную синхронизацию. |
| `seo` | Существующая серверная проекция между JSON и scalar | Скрыть дублирующий редактор, сохранить legacy fallback, неизвестные ключи и readback после записи. |
| `translations` | Сохраняемые дополнительные данные, без подтверждённого публичного сценария A3 | Понятное резюме, без raw JSON и нового редактора переводов. |
| `status` | `getCmsPage` выбирает только `published`; отдельная status mutation CMS | Сохранение содержимого не меняет публикацию. Обычная публичная ссылка не является предпросмотром черновика. |
| `page_sections` | Отдельная выборка `getSections`, затем `CmsSections` | Отдельные буферы и сохранение каждого блока; сохранение страницы не сохраняет блоки. |
| `home_page.source_page` и системные типы/адреса | Существующая защита Pages controller | Fail-closed чтение связи и прежняя блокировка сохраняются. |
| `COMMERCE_STOREFRONT_URL` | Новый authenticated read-only `GET /commerce/config/storefront` | Единственный подтверждённый источник базы сайта; отсутствующая или небезопасная база не даёт активной ссылки. |

Для `/about`, `/delivery`, `/contacts`, `/payment` опубликованная запись с соответствующим slug заменяет встроенное содержимое. После снятия записи с публикации встроенная страница остаётся доступной. A3 объясняет это в отдельном диалоге публикации и не обещает исчезновения маршрута.

Источники: `storefront/lib/content.ts`, `storefront/components/CmsPageRenderer.tsx`, `storefront/app/[slug]/page.tsx`, `storefront/app/{about,delivery,contacts,payment}/page.tsx`, существующие Pages controller и серверные SEO-проекции. Проверка исходников не заменяет установленную runtime-приёмку; её факты фиксируются отдельно.
