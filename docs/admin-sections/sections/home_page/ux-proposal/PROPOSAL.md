# A2-UX-FIX · предложение для «Главной страницы»

Этот автономный макет показывает один вариант интерфейса для согласования. Он не подключён к Directus, не читает и не меняет данные, не является установленной CMS. Все введённые в поля значения служат только визуальным примером.

## Что показано

Откройте `prototype.html` локально. Страница поддерживает ширину 1536×1024 и 390×844; на телефоне административная боковая навигация сворачивается, а рабочая область становится одноколоночной. Вкладки доступны через ссылки.

| Экран | URL-параметры |
| --- | --- |
| Первый экран | `?view=hero` |
| Блоки страницы — фактическое пустое состояние | `?view=blocks` |
| Поиск и ссылки, группа поиска раскрыта | `?view=search` |
| Дополнительно | `?view=other` |
| Сравнение при конкурентном изменении | `?view=conflict` |
| Пример блока: черновик | `?view=blocks&state=draft` |
| Пример блока: опубликован и включён | `?view=blocks&state=published` |
| Пример блока: опубликован, но скрыт | `?view=blocks&state=hidden` |
| Пример незнакомого типа | `?view=blocks&state=unknown` |

Заполненные состояния блока явно подписаны как пример макета: сейчас у главной страницы нет редактируемых блоков. Они показывают отдельное сохранение блока и различие между статусом публикации и флажком показа. В live metadata `items` и `settings` представлены как JSON-поля, а не native repeater. Макет не предлагает ручное редактирование JSON: для элементов указан конкретный блокер удобного редактора и приведён отдельный синтетический пример просмотра; дополнительные настройки оставлены только для чтения.

## Предлагаемые изменения

- Убрать пустое «Основное» из навигации. На первом экране сразу видны поля, реально меняющие заголовок и текст сайта, изображение с его описанием и две пары кнопок.
- Уточнить условие показа кнопки: требуются подпись и допустимая ссылка; пустые или некорректные значения могут привести к стандартной кнопке сайта. Макет не обещает скрытие кнопки при очистке текста.
- В «Поиск и ссылки» оставить единый ввод поискового заголовка и описания. Параметры подсказки и подписи кнопки поиска вынести в раскрытую группу и объяснить их реальное влияние на поиск в шапке. Канонический адрес и индексирование описать простым языком. Резервный `h1` скрыть под отдельным раскрытием и пояснить, что это не видимый заголовок первого экрана.
- Оставить поля, не имеющие подтверждённого самостоятельного эффекта, в «Дополнительно» только для чтения с конкретным объяснением. Проекция поискового заголовка и описания сохраняет прочие значения панели поиска; отдельные сохранённые заголовок, описание и изображение карточки ссылки не показываются как активные настройки. Карточка ссылки объяснена через основной заголовок и описание, а также изображение первого экрана.
- Сохранить один общий индикатор несохранённых изменений, но назвать действие «Сохранить главную». Для существующего блока предусмотрено отдельное «Сохранить блок». Конфликт явно сообщает, что блок уже сохранён, а ввод главной остался локальным; «Обновить и оставить мои изменения» обозначено как сравнение/согласование, а не сохранение.

## Основание и границы

Снимки «До» — предоставленные фактические экраны установленного локального Directus: `before-hero-*`, `before-seo-*`, `before-blocks-*`, `before-search-*`, `before-main-*` и `before-other-*`. Их внешний вид соответствует native Directus shell с rail шириной 54 px, навигацией 225 px и верхней полосой 54 px на desktop; на мобильном shell сворачивается.

Текущие значения проверены в read-only singleton: `Synthetic parts catalog`, `Neutral local integration content.`, пустые подписи и ссылки кнопок, изображение 1×1 px `Generated synthetic acceptance fixture` с описанием `Generated synthetic test image`, поле поиска `Enter a synthetic part number` и кнопка `Search`. Поля поискового заголовка и описания пустые; индексирование включено; резервный заголовок использует `Synthetic acceptance home` и поисковое описание. В дополнительных группах показаны проверенные текущие значения подписи поиска и ссылок на запрос, таблицу и фотографию. Данные карточки при отправке ссылки и переводы пусты. Содержимого каталога, клиентов и владельца источника здесь нет. Синтетический пример элемента блока не является записью базы.

Потребители проверены по актуальному локальному коду storefront, A2 материалам и read-only live metadata: видимый H1 читает `hero_title`; `h1` служит резервным значением метаданных; `hero_text` и `hero_image` питают первый экран; placeholder и текст кнопки поиска передаются в шапку через layout; поисковые заголовок и описание проецируются в SEO-панель с сохранением неизвестных значений. Публичная главная не запрашивает дополнительные ссылки на список/таблицу/фотографии и отдельные сохранённые значения для карточки ссылки. Раздел блоков читает только опубликованные дочерние записи, затем применяет условие показа; фактическая выдача на сайте может зависеть от обновления кеша. `items` и `settings` в текущей установке — JSON-поля без удобного редактора. Незнакомый тип может показать общие поля; его специальное оформление не подтверждено. Текущая база не содержит блоков, поэтому список примеров не изображает реальные данные.

Подтверждённый target задачи — существующий локальный Directus 12.1.1 на `http://127.0.0.1:18056`, Compose-проект `universal-commerce-cms-dev`, Windows. Установленное расширение подключает bind из `C:/Users/Alexandr/.codex/worktrees/storefront-directus-acceptance/Universal Commerce CMS/directus/extensions`. Публичный сервер не подтверждён. Этот макет не установлен и не является опубликованным bundle.
