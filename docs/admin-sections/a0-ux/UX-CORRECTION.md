# Возврат с пользовательской приёмки

20 октября 2026: владелец отклонил экран категории. Предыдущая техническая проверка не означает визуальную приёмку; публикации не было.

Подтверждено в установленном Directus: неактивные вкладки и category-note имеют rgb(162,181,205) на белом; native input 54 px, form row-gap 36 px. Два постоянных технических предупреждения занимают место над формой. Макет A0 показывал фрагменты действий, а не эту форму; он не является доказательством соответствия всего экрана.

Запрошенное поведение: читаемый компактный рабочий экран без технических лекций; ограничение родительской категории остаётся, выражено короткой подписью рядом с полем. Обычные поля, понятные группы и вторичные изображения не должны создавать лишнюю прокрутку desktop.

Разрешено: admin-shell.js для вкладок/панели и categories.js для текстов, scoped-плотности и view-only widths, их dist-пары; адресные поведенческие тесты и доказательства. Не менять значения, правила форм, CAS, permissions, schema, identifiers, зависимости, остальные разделы, production или PR #14. Один worker, без параллельного writer.

Проверка: фактический diff и src/dist, адресный category/admin-ux check, один desktop/mobile screenshot pass на настоящем Directus с computed dimensions/colors и сравнением с жалобой; не скрывать поля/overflow ради высоты. При необходимости один bounded fix pass. Итоговый verify-local на окончательном source. Пользовательская приёмка остаётся открытой до нового решения владельца.
