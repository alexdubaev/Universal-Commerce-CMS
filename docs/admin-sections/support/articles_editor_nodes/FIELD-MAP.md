# Поля: Узлы редактора статей

Статический снимок blueprint/Studio, 2026-10-02. Это не выгрузка фактической БД. Требования readonly ниже дополнительно ограничивают UI; они не изменяют native permissions.

Владелец UI-компонента: articles. Это распределение задач, а не schema-связь или родительская коллекция. См. ../../CONTRACTS.md и ../../NATIVE-SURFACES.md.

Ограничение всей коллекции: **Штатный Flexible Editor; без прямой записи отдельной формой**. Оно имеет приоритет над общей пометкой «По правам и контракту» в таблице ниже.

| Поле | Подпись | Тип | Обязательное | Режим нового UI | Допустимые значения / связь | Native group/interface |
|---|---|---|---|---|---|---|
| id | id | uuid | Да | Только просмотр | — |  |
| articles_id | articles_id | uuid | Да | По правам и контракту | "articles" |  |
| collection | collection | alias | Нет | Только просмотр | — |  |
| item | item | uuid | Нет | По правам и контракту | — |  |
