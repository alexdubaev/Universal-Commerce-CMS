# Данные и решения для владельца СМ ТЕХНО

Эти сведения нельзя установить из репозитория. Они не заменены вымышленными фактами.

- Настройки собственного Directus: реальные телефон/email, адрес посещения, режим работы и реквизиты. Облачный preview использует демонстрационные данные mock mode.
- Сведения о компании: история, склад/география, подтверждённые услуги и преимущества. Сейчас текст опирается только на роль поставщика и фактический ассортимент каталога.
- Условия оплаты, НДС, документы, перевозчики, стоимость и сроки доставки.
- Production URL для NEXT_PUBLIC_SITE_URL — единого источника canonical, Open Graph, sitemap и JSON-LD. Production-домен не придуман.
- Кто утверждает три черновика, реальное авторство и фактическую дату публикации. Черновики не опубликованы. Технический updated_at не объявлен датой существенного обновления.
- Нужны ли самостоятельные встроенные изображения, помимо обложки и OG image. Файл должен уже иметь разрешённую опубликованную связь; общая папка uploads не открыта.
- Достоверность аналогов и применяемости в CMS. Совместимость не определяется сходством артикула. View model теряет направление superseded_by, поэтому подпись «Связь замены» нейтральна.
- Отдельный импорт черновиков в собственном экземпляре CMS и ручная публикация после проверки. Реальная CMS в этой задаче не изменяется, заявки/письма не отправляются, сайт не развёртывается.
