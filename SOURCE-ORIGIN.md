The final access blueprint narrows file and order permissions based on the second-review ruling. Directus 12.1.1's installed Files controller attempts a `readOne` after multipart POST and suppresses the response payload on a Forbidden read, so frontend file reads include public assets plus only that account's own private uploads. Its installed dynamic-variable helper resolves `$CURRENT_USER` from the active accountability user. The frontend may create orders and order items, but reads only its own order's idempotency fields; Content and SEO policies have no order permissions.

Destination review adaptation: Content Manager and SEO Manager file reads are limited to the local Public assets folder.
